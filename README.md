# homebrew-tap

Homebrew formulae for programs I have made.

## Installation

```
brew tap hmerritt/tap
brew install <FORMULA>
```

## Formulae

| Repository                                                        | Formula                               | Description                                                                                                       |
| ----------------------------------------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [auto-extract](https://gitlab.com/mrrttjd/auto-extract)           | [formula](Formula/auto-extract.rb)    | Watches your Downloads directory (or any directory) for ZIPs and archives and automatically extracts them for you |
| [exifmeta](https://github.com/hmerritt/exifmeta)                  | [formula](Formula/exifmeta.rb)        | EXIF read/write/remove tool — useful for film photographers                                                       |
| [fspop](https://github.com/hmerritt/fspop)                        | [formula](Formula/fspop.rb)           | Automate the creation of file structures using custom templates                                                   |
| [ics-to-markdown](https://github.com/hmerritt/go-ics-to-markdown) | [formula](Formula/ics-to-markdown.rb) | ICS->Markdown. Convert a calendar ICS file into a Markdown table                                                  |
